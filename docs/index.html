Viết SQL thuần,
bỏ phần JDBC rườm rà.

FlowSQL là thư viện JDBC gọn nhẹ của Devhub Solutions: connection pool HikariCP, named parameter :name, transaction theo thread và auto-config cho Spring Boot. Không ORM, không phép thuật.

Bắt đầu GitHub Maven Central Javadoc
Pool cấu hình sẵnMySQL, MariaDB, PostgreSQL, H2 trên HikariCP.
Named parameter an toànKhông nhầm ::cast, chuỗi '10:30' hay comment.
Transaction theo threadinTransaction(...) tự commit/rollback.
Spring BootKhai báo trong application.yml là dùng.

Cài đặt

FlowSQL không kèm JDBC driver — thêm driver của database bạn dùng.

<!-- Maven -->
<dependency>
  <groupId>vn.io.devhub</groupId>
  <artifactId>flowsql</artifactId>
  <version>1.0.0</version>
</dependency>
<dependency>
  <groupId>com.mysql</groupId>
  <artifactId>mysql-connector-j</artifactId>
  <version>8.4.0</version>
</dependency>
// Gradle
implementation("vn.io.devhub:flowsql:1.0.0")
runtimeOnly("com.mysql:mysql-connector-j:8.4.0")

Dùng nhanh

import vn.io.devhub.flowsql.*;
import static vn.io.devhub.flowsql.DataSet.params;

DataSet db = DataSet.mysql()
        .host("localhost").database("shop")
        .user("app").pass(System.getenv("DB_PASS"));

List<Map<String, Object>> users =
        db.query("SELECT id, name FROM users WHERE status = :st", params("st", "ACTIVE"));

Object id = db.insert("INSERT INTO users(name) VALUES(:n)", params("n", "Thành"));

db.inTransaction(() -> {
    db.execute("UPDATE acc SET bal = bal - :v WHERE id = :id", params("v", 100, "id", 1));
    db.execute("UPDATE acc SET bal = bal + :v WHERE id = :id", params("v", 100, "id", 2));
});

Tạo DataSet

Mỗi DataSet là một connection pool. Tạo một DataSet cho mỗi database rồi dùng chung — nó thread-safe. Pool được tạo lười ở lần truy vấn đầu tiên.

DataSet.mysql()  DataSet.mariadb()  DataSet.postgres()  DataSet.h2("test")

DataSet db = DataSet.postgres()
        .host("db.local").port(5432).database("app")
        .user("app").pass(secret).ssl(true)
        .maxPoolSize(20).minIdle(5)
        .slowQueryMs(500)        // log WARN câu lệnh chậm
        .leakDetectionMs(0);     // 0 = tắt

new DataSet(DBType.MYSQL).jdbcUrl("jdbc:mysql://...");   // URL tự viết
new DataSet(existingDataSource);                         // bọc pool có sẵn, FlowSQL không đóng nó
MySQL/MariaDB: mỗi connection được ép time_zone = '+00:00' để NOW() và giờ phía Java khớp nhau. Hãy lưu và so sánh thời gian theo UTC.

API truy vấn

Các phương thức dưới đây ném FlowSqlException (unchecked) khi lỗi.

Phương thứcTrả vềDùng cho
query(sql, params)List<Map>, không bao giờ nullSELECT nhiều dòng
queryOne(sql, params)Optional<Map>SELECT một dòng
queryScalar(sql, params)ObjectCOUNT, MAX, EXISTS
execute(sql, params)int số dòngUPDATE, DELETE, DDL
insert(sql, params)Object khóa tự sinhINSERT có auto-increment
batch(sql, List<Map>)int[]Một câu lệnh, nhiều bộ tham số

params(k1, v1, k2, v2, …) tạo HashMap cho phép giá trị null; Map.of cũng dùng được nếu không có null.

Named parameter

  • Cú pháp :ten; một tên có thể dùng nhiều lần.
  • Mỗi :ten phải có key trong map (giá trị được phép null), nếu không sẽ báo lỗi.
  • Bỏ qua: col::text, nội dung trong '…' "…" `…`, comment -- và /* */.
  • Tham số chỉ dành cho giá trị. Tên bảng/cột/hướng sắp xếp phải được whitelist rồi nối chuỗi — không bao giờ nối input người dùng vào SQL.

Danh sách IN (…)

Map<String, Object> p = new HashMap<>();
StringJoiner in = new StringJoiner(", ");
for (int i = 0; i < ids.size(); i++) { in.add(":id" + i); p.put("id" + i, ids.get(i)); }
db.query("SELECT * FROM users WHERE id IN (" + in + ")", p);

Đọc kết quả

Key của map là nhãn cột viết thường. Dùng Rows để đọc không phân biệt hoa thường và có giá trị mặc định:

String name    = Rows.str(row, "NAME");
long   id      = Rows.getLong(row, "id", 0L);
boolean active = Rows.getBool(row, "active", false);   // true / 1 / Y
BigDecimal amt = Rows.getDecimal(row, "amount", BigDecimal.ZERO);

record User(long id, String name) {}
List<User> list = db.query("SELECT id, name FROM users").stream()
        .map(r -> new User(Rows.getLong(r, "id", 0), Rows.str(r, "name")))
        .toList();

Transaction

Transaction gắn với thread hiện tại: mọi lệnh FlowSQL trên cùng thread (cùng DataSet) tự tham gia.

Long orderId = db.inTransaction(() -> {
    Object id = db.insert("INSERT INTO orders(total) VALUES(:t)", params("t", 99));
    db.execute("UPDATE stock SET qty = qty - 1 WHERE sku = :s", params("s", "A1"));
    return ((Number) id).longValue();
});   // lỗi bất kỳ → rollback và ném lại

db.begin();
try { …; db.commit(); } catch (RuntimeException e) { db.rollback(); throw e; }
inTransaction lồng nhau sẽ tham gia transaction bên ngoài. Thread con không dùng chung transaction. Spring @Transactional không điều khiển transaction của FlowSQL.

Nhiều database

try (DataSetRegistry reg = new DataSetRegistry()) {
    reg.register("main", DataSet.mysql().host("a").database("app").user("u").pass("p"));
    reg.register("report", DataSet.postgres().host("b").database("bi").user("u").pass("p"));
    DataSet main = reg.get("main");
}

Spring Boot

Có dependency là auto-config chạy (Spring Boot 3), tạo bean DataSetRegistry từ flowsql.datasources.*:

flowsql:
  datasources:
    main:
      type: mysql            # mysql | mariadb | postgresql | h2
      host: db.local
      database: app
      username: app
      password: ${DB_PASS}
      max-pool-size: 20
      slow-query-ms: 500
    report:
      type: postgresql
      jdbc-url: jdbc:postgresql://bi:5432/bi
      username: bi
      password: ${BI_PASS}
@Repository
class UserRepo {
    private final DataSet db;
    UserRepo(DataSetRegistry registry) { this.db = registry.get("main"); }
}
